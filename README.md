# 子彈喵喵 (Bullet Meow)

可愛的貓咪戰機縱向卷軸射擊遊戲（HTML5 Canvas，純前端）。
玩家操作小貓在天空中擊退侵略家園的飛天老鼠。

## 遊玩
直接雙擊 `index.html` 用瀏覽器開啟即可（建議 Chrome / Edge），不需要安裝或建置。

| | 鍵盤 | 遊戲控制器 |
| --- | --- | --- |
| 移動 | 方向鍵 / WASD | 左搖桿 / 十字鍵 |
| 射擊 | 空白鍵（按住連發） | A / X / Y / RB / RT |
| 暫停 | Esc / P | Start |

M：音效開關　F：全螢幕。控制器連接後按任一鍵即可被瀏覽器偵測。

**手機 / 平板**：直接用手機瀏覽器開啟即可。按住畫面時手指位置才會出現虛擬搖桿圓盤（還沒按住時不顯示任何虛擬按鈕），戰機會飛到圓盤**正上方**並跟著手指移動（不會被手指擋住）；
放開後點新的位置，戰機會快速飛過去；**子彈自動連射，不需要按鈕**；右上角有 ⏸ 暫停按鈕（開啟暫停選單）。遊玩時畫面已鎖定，不會被拖曳、縮放、下拉重新整理或長按選單干擾。
（加到主畫面後可用全螢幕開啟；若接上鍵盤或手把，觸控介面會自動關閉。）

**BOSS**：每 5 波（第 5、10、15… 波）會出現「流氓大老鼠」——傘狀便便彈、丟起司、身體衝撞、爪擊（舉爪時有護盾會把你的子彈彈開）。
打贏他會看到他一臉厭世的死亡演出。

設計說明、敵機 AI 與平衡數據請見 [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)。

**晝夜變化**：遊戲中背景有白天、黃昏、黑夜三種，每 5 波換一次（打敗 BOSS 後平滑轉場），起司球在白天像太陽般有光芒、黃昏光芒慢慢減弱、黑夜沒有光芒；各有不同的場景小點綴（白天：小鳥、熱氣球；黃昏：海鷗；黑夜：流星、螢火蟲、UFO），數量不多、不影響遊玩。背景音樂也跟著時段換曲（白天明亮快板、黃昏懷舊慢板、黑夜神祕星空），每首曲子的編曲會隨旋律重複逐漸加上和聲、琶音、弦樂、銅管、鐘琴、電鋼琴、長笛、節奏低音與更密的鼓組（含過門與鈸）。

**排行榜**：全球玩家共用的前 **20 名**（Firebase 雲端，連不上網時自動改用本機紀錄），每筆記錄簽名、分數、GAME OVER 時的波數。進榜後可以**簽名**（4 個字元，A–Z、0–9）：鍵盤直接打字（Enter 送出）、手把 ↑↓ 換字 ←→ 換格 A 確定 B 退格 Start 送出、手機 / 滑鼠點畫面上的鍵盤（⌫ 刪除、OK 送出）。

**選單**：開始遊戲 / 排行榜 / 操作說明（「操作」「敵機介紹」兩個頁籤）/ 設定（由左至右「語言」「了解歷史」「CREDIT」三個頁籤，預設「語言」）。
語言可選**中文 / 日文 / 英文**，選擇後立即套用並記住。

## 部署與更新（上傳到 GitHub Pages 等網站時）
- **所有 `.js` 檔案都要上傳**（`index.html` 載入的每一個），少一個遊戲就會出錯。新增檔案時要特別確認有傳到。
- 主選單**左下角**會顯示版本號（例如 `v2026.09.21b`）。更新後如果版本號沒變，代表瀏覽器還在用舊快取：按 **Ctrl+F5** 強制重新整理（手機：清除網站快取）。
- `index.html` 與 `src/core/config.js` 的版本號必須一致（每次發佈一起更新，所以**這兩個檔案每次都要上傳**）；不一致、檔案缺少或載入失敗時，
  畫面上方會直接顯示紅色提示說明是哪個檔案有問題；遊戲執行中如果出錯，會顯示錯誤畫面（原因與出錯的檔案 / 行數），點一下即可重新整理，不會再默默卡住。

## 資料夾結構

| 資料夾 | 用途 |
| --- | --- |
| `index.html` | 遊戲入口頁 |
| `src/core/` | 設定、多語系（i18n）、輸入（鍵盤/手把）、觸控（虛擬圓盤/暫停鈕）、音效、主迴圈與場景切換 |
| `src/scenes/` | 場景：主選單、遊戲、結算 |
| `src/entities/` | 遊戲物件：玩家、敵機、BOSS、子彈、粒子 |
| `src/systems/` | 系統：敵機陣形、進場隊形（起司月亮）、4 種敵機 AI、波次與出擊調度 |
| `src/ui/` | 貼圖（程式繪製）、背景、HUD |
| `src/utils/` | 共用工具：數學、繪圖、排行榜（雲端連線 `cloud.js` + 榜單快取 `storage.js`） |
| `assets/` | 外部素材：`images/sprites/player.png`（主角：貓咪噴射背包戰機）。其餘美術與音效皆由程式產生，其他子資料夾預留給之後的素材 |
| `styles/` | CSS 樣式 |
| `docs/` | 設計文件 |
| `tests/` | 測試 |

> 空資料夾內的 `.gitkeep` 只是為了讓 git 追蹤空資料夾，放入實際檔案後即可刪除。
