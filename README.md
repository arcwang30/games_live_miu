# 子彈喵喵 (Bullet Meow)

可愛的貓咪戰機縱向卷軸射擊遊戲（HTML5 Canvas，純前端）。
玩家操作小貓在天空中擊退侵略家園的飛天老鼠。

## 遊玩
直接雙擊 `index.html` 用瀏覽器開啟即可（建議 Chrome / Edge），不需要安裝或建置。

| | 鍵盤 | 遊戲控制器 |
| --- | --- | --- |
| 移動 | 方向鍵 / WASD | 左搖桿 / 十字鍵 |
| 射擊 | 空白鍵（按住連發） | A / X / Y / RB / RT |
| 暫停 | Esc / P | Start |

M：音效開關　F：全螢幕。控制器連接後按任一鍵即可被瀏覽器偵測。

**手機 / 平板**：直接用手機瀏覽器開啟即可。按住畫面時手指位置會出現虛擬搖桿圓盤，戰機會飛到圓盤**正上方**並跟著手指移動（不會被手指擋住）；
放開後點新的位置，戰機會快速飛過去；**子彈自動連射，不需要按鈕**；右上角有 ⏸ 暫停按鈕（開啟暫停選單）。遊玩時畫面已鎖定，不會被拖曳、縮放、下拉重新整理或長按選單干擾。
（加到主畫面後可用全螢幕開啟；若接上鍵盤或手把，觸控介面會自動關閉。）

**BOSS**：每 5 波（第 5、10、15… 波）會出現「流氓大老鼠」——傘狀便便彈、丟起司、身體衝撞、爪擊（舉爪時有護盾會把你的子彈彈開）。
打贏他會看到他一臉厭世的死亡演出。

設計說明、敵機 AI 與平衡數據請見 [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)。

## 資料夾結構

| 資料夾 | 用途 |
| --- | --- |
| `index.html` | 遊戲入口頁 |
| `src/core/` | 設定、輸入（鍵盤/手把）、觸控（虛擬圓盤/暫停鈕）、音效、主迴圈與場景切換 |
| `src/scenes/` | 場景：主選單、遊戲、結算 |
| `src/entities/` | 遊戲物件：玩家、敵機、BOSS、子彈、粒子 |
| `src/systems/` | 系統：敵機陣形、4 種敵機 AI、波次與出擊調度 |
| `src/ui/` | 貼圖（程式繪製）、背景、HUD |
| `src/utils/` | 共用工具：數學、繪圖、排行榜儲存 |
| `assets/` | 外部素材：`images/sprites/player.png`（主角：貓咪噴射背包戰機）。其餘美術與音效皆由程式產生，其他子資料夾預留給之後的素材 |
| `styles/` | CSS 樣式 |
| `docs/` | 設計文件 |
| `tests/` | 測試 |

> 空資料夾內的 `.gitkeep` 只是為了讓 git 追蹤空資料夾，放入實際檔案後即可刪除。
